# Reproducibility Manifest

This manifest maps the manuscript tables and figures to scripts, inputs, and
outputs. Paths are relative to the project root unless noted otherwise.

## Environment

- Python: use the project environment that can import `torch`, `numpy`,
  `matplotlib`, and the local `utils/` modules.
- Manuscript-side environment snapshot:
  `overleaf_inversion_paper/environment-repro.yml`.
- Recommended runtime variables for CPU runs:

```bash
export KMP_DUPLICATE_LIB_OK=TRUE
export OMP_NUM_THREADS=1
export MKL_NUM_THREADS=1
```

## Production Surface-Wave Commands

Matched DI-Strong/DI-Weak training requires retraining:

```bash
python pnas_publish/scripts/core/train_di_fair.py --config pnas_publish/configs/fair_di_strong_full.yaml
python pnas_publish/scripts/core/train_di_fair.py --config pnas_publish/configs/fair_di_weak_full.yaml
```

Evaluation and diagnostics can be rerun from existing checkpoints:

```bash
python pnas_publish/scripts/core/eval_fair_di_comparison.py \
  --strong-ckpt ckpt/fair_di_strong_full_seed642026/best.pt \
  --weak-ckpt ckpt/fair_di_weak_full_seed642026/best.pt \
  --out-dir results/fair_di_comparison/production \
  --fig-dir figures/fair_di_comparison/production \
  --n-test 1024 --n-envelope 10000 \
  --posterior-samples 64 --euler-steps 24 \
  --bootstrap 2000 --batch-size 16

python pnas_publish/scripts/core/eval_fair_calibration.py \
  --strong-ckpt ckpt/fair_di_strong_full_seed642026/best.pt \
  --weak-ckpt ckpt/fair_di_weak_full_seed642026/best.pt \
  --out-dir results/fair_di_comparison/production/calibration \
  --fig-dir figures/fair_di_comparison/production/calibration \
  --n-eval 2048 --calibration-examples 1024 \
  --posterior-samples 64 --euler-steps 24 --bootstrap 2000

python pnas_publish/scripts/core/eval_fair_noise_sensitivity.py \
  --strong-ckpt ckpt/fair_di_strong_full_seed642026/best.pt \
  --weak-ckpt ckpt/fair_di_weak_full_seed642026/best.pt \
  --out-dir results/fair_di_comparison/production/noise \
  --noise-sigma-km-s 0.00 0.02 0.05 0.10 \
  --n-eval 1024 --posterior-samples 64 --euler-steps 24

python pnas_publish/scripts/core/eval_fair_missing_band.py \
  --ckpt ckpt/fair_di_weak_full_seed642026/best.pt \
  --out-dir results/fair_di_comparison/production/missing_band \
  --fig-dir figures/fair_di_comparison/production/missing_band \
  --n-eval 1024 --posterior-samples 64 --euler-steps 24
```

The envelope-shaded profile figure can be regenerated from archived diagnostics
without resampling posteriors:

```bash
python pnas_publish/scripts/core/make_fair_example_profiles_with_envelope.py \
  --diagnostics results/fair_di_comparison/production/fair_di_diagnostics.npz \
  --output figures/fair_di_comparison/production/fair_di_example_profiles.pdf \
  --n-envelope 10000
```

## Metric Smoke Test

```bash
python pnas_publish/scripts/core/envelope_metric_smoke_test.py
```

This test verifies the conditional pull-in denominator for edge cases with no
outside-envelope target nodes, all outside target nodes, and mixed support.

## Current Limitations and TODOs

- Table 1 direct-model rows include bootstrap confidence intervals from
  `fair_di_metrics.csv`. IND-FWD rows currently use aggregate baseline metrics;
  confidence intervals require archived per-example IND-FWD outputs.
- Table 2 gravity rows currently use aggregate metrics. Confidence intervals
  require saving per-example gravity predictions and residuals.
- A transparent linear gravity baseline, such as Tikhonov-regularized least
  squares or truncated SVD, remains a useful pre-submission addition. It is not
  reported in the manuscript because no archived output exists yet.
- Exact-forward optimization for IND-FWD is not reported. The manuscript reports
  exact-solver post-check residuals for recovered models and treats surrogate
  optimization outside support as a limitation.
